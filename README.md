## 🧩 What I've Built

- **Autonomous GRC / automated compliance platforms** — control mapping, evidence automation, and framework coverage at scale
- **External Attack Surface Management (EASM)** — discovery, enumeration, and continuous exposure monitoring
- **Cyber Risk Quantification (CRQ) models** — translating technical risk into financial terms for decision-making

## 🚀 Featured Projects

### Security & Reconnaissance
- **[ratnosint7](https://github.com/Ratnadeepdeyroy/ratnosint7)** - High-performance Go-based subdomain reconnaissance engine that orchestrates multiple enumeration tools
- **[docker-security](https://github.com/Ratnadeepdeyroy/docker-security)** - Docker security analysis engine with Dockerfile linting, SBOM, CVEs, secrets detection, and compliance checks

### AI Security & Tooling
- **[ai-watch](https://github.com/Ratnadeepdeyroy/ai-watch)** — Local-first VSCode extension giving visibility and policy guardrails over AI coding assistants; records every prompt, applies regex/glob/AST/LLM policy rules, and blocks or redacts secrets before they leave the machine. Encrypted on-disk storage, OS-keychain keys, no telemetry. [Marketplace ↗](https://marketplace.visualstudio.com/items?itemName=RatnadeepDeyRoy.aiwatch)

### AI & Agent Systems
- **[agentonomics](https://github.com/Ratnadeepdeyroy/agentonomics)** - The Economics of AI Agents
- **[loop-engineering](https://github.com/Ratnadeepdeyroy/loop-engineering)** - Exploring iterative reasoning, self-improvement, evaluation loops, and autonomous execution for AI agents
